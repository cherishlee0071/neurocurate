# Subject-01 first real EEG scientific result

1. **Valid Brain RDM: yes.** Real float64 EEG (200,80,17,100), 100 Hz, 17 posterior channels, 80 repetitions/image. Features (200,680), correlation RDM (200,200). Finite, symmetric, zero-diagonal and saved-order/recomputation checks pass. All 200 numeric condition mappings and distinct stimulus files validate.
2. **Repetition-split reliability:** median Spearman **0.7065**; random-split 95% variability interval **[0.6774594078606642, 0.7235964799660619]**, 30 disjoint 40/40 splits. This interval is not a population confidence interval.
3. **Permutation control:** median null **-0.0001**, null 95% interval **[-0.048927460524746454, 0.04692939411634127]**; one-sided Monte Carlo **p=0.000999**, 1,000 image-label permutations preserving matrix symmetry and pair dependencies.
4. **Disagreement stability: moderate score-ranking repeatability, NOT a definitive stable shortlist.** Primary mean-model K=10 ranking Spearman median **0.4846**, variability interval **[0.4019888288652746, 0.5611493114807622]**. Top-20 overlap fraction median **0.250**; tie-aware permutation null median **0.150**, **p=0.0010**. Full top-20 boundary tie size **29**; the visualized 20 are one deterministic selection from this tied group. Uniform-random overlap 0.10 is NOT the appropriate tie-aware control. K=5/10/20 and individual-model results are in disagreement_stability.json. Rankings require cross-subject replication.
5. **Exploratory scope:** ALL reliability, model comparison and ranking results are conditional on supplied whitening estimated using both training/test partitions and all repetitions. Halves have disjoint repetitions, not independently fitted preprocessing or independent sessions. Repeated random splits overlap. No cross-subject consensus, training improvement, label quality or causal benefit is established.
